Install App — mockup rev 2 · unified

Real design tokens from src/styles/design-tokens.css. Every platform now gets the same sheet: same app mark, same title, same numbered-step layout, same two-button row. Only the words inside change.

What changed in rev 2: Android no longer jumps straight to Chrome's dialog. It opens our sheet first, exactly like iOS, and the primary button hands off to the OS. Costs one extra tap on Android; buys an identical look on every phone. The app mark, the numbered pills, the button row and the sheet geometry are now literally the same component everywhere — the platform difference lives only in the step text.
