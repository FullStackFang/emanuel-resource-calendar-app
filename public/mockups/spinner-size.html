Emanuel Resource Calendar · Loading mark · sizing

How big should it be?

The shared default was 48. It is now 64. Below is the same mark at five sizes, then the two sizes side by side in the real variant="card" and variant="overlay" shells — same padding, same shadow, same copy as the app renders.

The size rail

Detail is not uniform across this rail. Keystones only render at 48 and above, so the mark gains ornament as it grows rather than merely scaling — which is why 64 reads as noticeably more finished than 48, not just larger.

Not changed: the ten call sites that pass an explicit size — the Clergy and Category pickers and the Scheduling Assistant overlay at 40, the Approval Queue inline gate at 32, and the attachment upload rows at 16 (which fall through to the conic ring).
